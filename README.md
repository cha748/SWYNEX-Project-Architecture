# SpendWise - Project Architecture

A small full-stack web app to track daily expenses, group them by category, and see monthly totals.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB

## Folder Structure
- `client/` - React frontend
- `server/` - Express API
- `docs/` - Architecture document
